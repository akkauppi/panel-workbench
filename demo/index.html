Smaller cells at sharper bends

Adapt to curvature places more cell centres where the shell bends more sharply, with gradual transitions towards larger cells in flatter areas. Regularized surface keeps these size differences while improving the arrangement.

Minimum and maximum are target distances between cell centres, not strict limits on each panel's dimensions. Openings, borders and later manual edits affect the actual shapes. Fitting and stock checks still apply.

Choose New arrangement to apply the range. This replaces the current layout; Undo restores it. Opening a saved project or changing stock settings keeps its accepted layout.

If the range needs more than 240 cells, increase the target sizes. Sharp creases and noisy meshes still need review.

What can I import?

Rhino .3dm: visible meshes, including meshes inside nested blocks. Document units are converted to millimetres; Rhino's Z axis stays vertical.

Rhino surfaces and polysurfaces: their saved render meshes are used. If those are missing, run Mesh in Rhino and export the resulting mesh as .3dm. Trims and openings must be retained.

Rhino curves: when the file has only curves, use one closed planar outer boundary and optional coplanar closed openings. Polylines are exact; curved outlines are approximated within 0.1 mm. Open curves and general 3D curve networks need a surface or mesh created in Rhino first. Curves alongside meshes are ignored.

OBJ: polygon mesh surfaces. Check source units after import.

Study JSON: use Open study to restore editable panel arrangements and settings. Importing CAD geometry creates a new source; it does not restore the previous editing history. Imports stay in your browser.

What objects are exported?

Rhino production .3dm (Rhino 6/7/8): one named block definition per panel, such as P001. Each contains the full panel mesh and closed nominal outline curves. Two instances share it: one assembled, one lying flat beside the assembly with its bottom at Z = 0.

Rhino repair .3dm: explicitly includes unresolved panels. Usable solid candidates are retained; where no solid exists, the source surface patch and available fitted outline candidates are included. Panel IDs and failure reasons are stored as object user text. The second set is arranged for inspection and may contain curved surfaces, zero-thickness meshes or crossing outlines. Repair and check these parts in Rhino before fabrication.

Your selected geometry: thickness, mitres and rounding are retained. Carving is included only when enabled. Flat placement keeps the full thickness. These are meshes inside genuine Rhino blocks, not reconstructed smooth NURBS solids.

Linked editing: Rhino BlockEdit updates both instances. Moving an instance changes only that placement. Editing an outline curve does not rebuild the panel mesh or its bevels.

Production preparation: rows provide spacing, not sheet nesting. Outlines are nominal panel boundaries, not bevel envelopes or compensated cutter paths. Check stock, orientation and tool access, then create toolpaths in CAM.

OBJ: meshes for the current view. STL: triangulated solids; import as mm. DXF: loose flat outline polylines and panel labels, without linked blocks. Study JSON: the editable app design.

Laser scale model

Unfold fitted panels into connected pieces for a 400 × 400 mm bed. Matching seam labels show where separate pieces join.

0 mm makes a score centreline (Line mode); a wider groove makes a closed engraving band (Fill mode). Groove width is measured on the small model.

Reverse folds appear as green centre lines on the front. Use 0 mm groove width for paper/cardboard line scoring. The green guides mark fold locations; they do not change the plywood groove face.

Prepare the sheets to preview them, or start with a plywood hinge coupon.

    Thin plywood test: scoring alone may not make a reliable hinge. Test the coupon on your material and choose power, speed, passes and remaining thickness in LightBurn. These files do not include machine settings, kerf compensation, glue tabs or bend allowance.

    What is in the laser SVG?

    2D vectors in millimetres: scaled fitted panel outlines, openings, fold guides, panel IDs and matching join labels. The full-thickness carved solids are not used. A valid outline can be used even if its full-size stock solid is unresolved.

    LightBurn layers: black cuts, blue fold grooves, red labels, gray alignment references. The coupon adds cyan filled groove bands. With all hinge guides enabled, green centre lines also mark reverse folds on the front for paper/cardboard. Colours separate operations; set their modes, order, power and speed yourself. For two-sided work, engrave the back first, flip, then engrave the front and cut last.

    Front and back: fold direction chooses the groove face. Back artwork is mirrored left-to-right about the 400 mm sheet centre. Use a registered flip jig and the same sheet origin. The four gray reference circles keep a common artwork size; disable their laser output. Back files contain no cutting paths. Registration requires a physical test.

    Assembly: overlap, curvature and sheet size can require separate nets. Match identical seam labels and tape or glue those edges together. Flat geometry does not predict whether plywood will bend without cracking or how material thickness changes the fit.

    Incomplete export: Whole model requires every fitted outline to be valid. Resolved outlines only deliberately omits failed panels and lists them in the preview.
